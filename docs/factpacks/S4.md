# S4. Colours across K, and a greyscale check

Date: 2026-10-24. This note records named bar palettes, a lock that keeps an aligned column's colour across K, and an optional greyscale preview. The default palette changed from the previous 20 colours to the Science palette. `--palette classic` restores the previous colours. `--id-col` stays `analysis_IID`. `--group-col` stays `Dong_Grp`. This note makes no colour-blind claim for any palette.

## Flags

`--palette` is `science`, `classic`, `tab10`, `set1`, `dark2`, or `paired`. The default is `science`.

`--color-lock` is `off` or `on`. The default is `off`. `on` keeps the colour aligned column c received at the lowest K, unless `--color` sets that column.

`--greyscale-preview` is off by default. It writes `panel_grey.png`. A default run does not write that file.

`--color` still wins over the palette and over the lock. A stored default of `--color-lock off` is the same as omitting the flag.

## Continuation and the lock

For `classic`, column c still starts at index c of the 20 colours. Past the end, `hsv_hex(i)` uses that same index, so the tail still starts at 20.

For every other name, the finite list is the named colours, then classic colours whose hex is not already in the named list. The comparison is the exact hex, ignoring case. `hsv_hex(i)` then uses the index in that combined list. None of the science, tab10, set1, dark2, or paired hexes equals a classic hex, so each of those palettes continues with `#0072b2`, then `#d55e00`, and then the rest of the classic list. At K = 8 the default palette is the eight science hexes in order. At K = 10 the last two are `#0072b2` and `#d55e00`.

`assign_colors` takes `lock_from=None` and `palette="science"`. Pass 1 is an explicit column colour from `--color`. Pass 2, when `lock_from` is set, copies the colour from the lowest K for that column. Pass 3 is a group colour. Pass 4 is the palette. K is walked from low to high. A colour stored from a lower K is not replaced at a higher K. `--color` on that column is pass 1, so it replaces the lock. If that hex is already used by another column, the existing used-set rule assigns the next free colour.

`--color-lock off` leaves each K on its own, which is what the previous code did, on top of whichever palette is selected.

When a flow figure is drawn without a colour list, the node fallback remains the classic 20 colours.

## Greyscale

The preview is qbar's own. It is not a simulator of colour vision. Each pixel of the drawn figure becomes `round(0.2126*R + 0.7152*G + 0.0722*B)` on all three channels. The coefficients are the ones in that expression. A red pixel `(255, 0, 0)` becomes `round(0.2126*255)` on every channel.

When more than one K is drawn, `panel_grey.png` is that conversion of `panel.png`. When one K is drawn, there is no `panel.png`, and `panel_grey.png` is that conversion of `bar_K*.png`. No PDF is written for the preview.

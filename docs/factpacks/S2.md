# S2. More input formats

Date: 2026-10-22. This note records `--q-format` and `--ind`. The default remains `.Q`. No alignment formula changed.

## Sources

Opened 2026-10-22.

### fastStructure .meanQ

The file is the posterior mean of the admixture proportions. Sample order matches the sample file passed separately. There is no header and no identifier column.

- README: https://github.com/rajanil/fastStructure/blob/master/README.md
- Same text: https://rajanil.github.io/fastStructure/
- Paper: Raj, Stephens, and Pritchard 2014, Genetics, DOI 10.1534/genetics.114.164350
- Real file: `test/testoutput_simple.3.meanQ` at commit `8f2d1b04979216f63ab74881a79dfb6fa97e8259`. https://github.com/rajanil/fastStructure/blob/8f2d1b04979216f63ab74881a79dfb6fa97e8259/test/testoutput_simple.3.meanQ
- That file has 200 lines and 3 columns. The first line is `0.771684  0.227893  0.000423`.
- This repository does not contain that file.

### NGSadmix .qopt

One line per individual. Ancestry proportions from each ancestral population.

- Manual: https://www.popgen.dk/software/index.php/NgsAdmixv2
- Paper: Skotte, Korneliussen, and Albrechtsen 2013, Genetics, DOI 10.1534/genetics.113.154138
- `ngsadmix32.cpp` `printDouble`, lines 717-722, writes `%.20f ` for each column and then a newline. Lines 1723-1724 call `printDouble(Q, nInd, nPop)`.
- No finished `.qopt` file was downloaded.

### EIGENSTRAT .ind

Three whitespace-separated columns: sample ID, gender (`M`, `F`, or `U`), and a label. qbar uses column 1 as the sample ID.

- `CONVERTF/README` at commit `d0afed4fbfac29e8cd74ee7533fdee996c55b9c0`, lines 56-60. https://github.com/DReichLab/EIG/blob/d0afed4fbfac29e8cd74ee7533fdee996c55b9c0/CONVERTF/README
- `CONVERTF/example.ind` at that commit has five lines. The first line begins with a tab.

Three non-actions:

- qbar does not read gender.
- qbar does not turn the label into a group.
- qbar does not drop a row labelled `Ignore`.

The 39-character ID limit in that README is not enforced.

## Flags

`--q-format` choices are `admixture`, `meanq`, and `qopt`. The default is `admixture`.

`--ind` is a path. The default is off.

`--fam`, `--ids`, and `--ind`: at most one. If more than one is set, the program exits and the message names every flag that was set. If none is set, the message stays `需要 --fam（PLINK .fam）或 --ids（一行一个 IID，顺序与 Q 的行一致）`.

`meanq` and `qopt` use the same numeric read as `admixture`. A non-numeric token exits with `Q 只能是空白分隔的数字` and the path. Trailing spaces are accepted.

After `lower()`, `admixture` requires extension `.q`, `meanq` requires `.meanq`, and `qopt` requires `.qopt`. A wrong extension exits with the path and the format name.

The filename K is the digit token immediately before that extension. `toy.3.meanQ` has filename K 3. `myoutfiles.qopt` has no filename K. If a filename K is present and differs from the column count, the exit text is `%s 文件名是 K=%d，列数是 %d`. The K used by the rest of the program is the column count.

A directory is globbed as follows. `admixture` uses `*.Q` then `*.q`. `meanq` uses `*.meanQ` then `*.meanq`. `qopt` uses `*.qopt` then `*.QOPT`. The same real path is kept once. Default `admixture` does not pick up a `.meanQ` sitting in the directory. An explicit path is accepted when the format matches.

`load_q_set(paths)` with no format still reads `.Q`. `api.run` passes `args.q_format`.

## Example

Working directory: repository root. `PYTHONHASHSEED=0`. `PYTHONDONTWRITEBYTECODE=1`. This run used Python 3.9.6.

```
python qbar.py --q demo/s2/toy.2.meanQ --ind demo/s2/toy.ind --q-format meanq --outdir demo/out/s2
```

`demo/s2/toy.2.meanQ` is:

```
0.20 0.80
0.70 0.30
```

`demo/s2/toy.ind` has a tab at the start of the first line, then `SAMPLE0`, gender `F`, and label `Case`. The second line is `SAMPLE1`, gender `U`, and label `Ignore`.

Stdout:

```
demo/out/s2/bar_K2.png
order	demo/out/s2/order.tsv
```

Stderr was empty.

`demo/out/s2/order.tsv`:

```
rank	iid	group
1	SAMPLE0	NA
2	SAMPLE1	NA
```

The group column is `NA` because no groups file was passed. The labels `Case` and `Ignore` were not used as groups. `SAMPLE1` was kept.

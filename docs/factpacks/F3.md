# F3. Standalone HTML with hover

Date: 2026-10-24. This note records an optional offline HTML panel. `--html` is off by default. A default run writes no `panel.html`. `--id-col` stays `analysis_IID`. `--group-col` stays `Dong_Grp`. `--palette` stays `science`.

## What the file contains

`--html` alone still writes only `panel.html`. A run with one K still writes that file, and it still does not write `panel.png`. The page holds a style element, one canvas, one tooltip element, one JSON script, and one drawing script. There is no SVG element and no per-cell rectangle element. There is no remote font. With `--cluster-flow sankey` it also writes `cluster_flow.html`, described in `docs/factpacks/F7.md`.

The canvas draws one row per K, lowest K at the top, the same order as the PNG. Samples are in the PNG order. Stacked colours are the hex values for that K, and column 0 is the bottom of the stack. Group spans use the same pixel truncation as the PNG (`left + int(start * bar_w / n)`). Group labels sit under the bars. A legend sits to the right. Colours and order match the PNG. Label placement is approximate: text width is estimated from the character count, not from a font file. The dendrogram is not drawn. Each sample slot is `bar_w / n`, with no extra overlap. The left margin is 56, the same value the PNG uses. The gap before the legend is 12.

The canvas backing store is `devicePixelRatio` times the CSS size, and the drawing transform uses that ratio. Hover works on each K row. The tooltip is filled with `textContent`. It shows the iid, the group, K, the run string, and Q for every column to 3 decimal places.

`write_panel_html` is in `qbar.html_panel`. The positional arguments are the path, the aligned matrices, the display order, the groups, the hex lists, and an optional run map. Sample ids are a required keyword, `iids`, because those positional arguments do not carry them. Optional keywords are `bar_w` (default 2200), `bar_h` (220 for one K, 120 for more than one), `title`, `rank`, `legend`, and `language`. The command passes the legend already built for the PNG. `panel_payload` builds the object. `panel_script` is the drawing script. `drawPanel` and `sampleIndexAt` are plain functions in that script, so a later editor page can call them.

## JSON keys

The object is the text of `<script type="application/json" id="qbar-data">`. Keys, in this order:

| Key | Meaning |
| --- | --- |
| `iid` | Sample ids in display order, the same order as `order.tsv` |
| `group` | Group label for each of those samples |
| `k` | K values from top to bottom |
| `run` | One string per K. Empty when replicates are off. A file name only, with no directory. See below. |
| `q` | One matrix per K. Each matrix is a list of samples in display order. Each sample is a list of numbers. Column 0 is first. |
| `column_names` | `C1`, `C2`, ... for each K, in aligned order |
| `hex` | Colour of each aligned column, the same list as `perm_K*.tsv` |
| `legend` | Legend text for each K, the same words as the PNG legend |
| `spans` | `name`, `start`, `end`, `x0`, `x1`. `start` and `end` are a 0-based half-open interval in display order. `x0` and `x1` are the pixel edges. |
| `layout` | `width`, `height`, `left`, `gap`, `bar_w`, `bar_h`, `leg_w`, `title`, `title_h`, `label_h`, `rotate_labels`, `n`, and `rows`. Each row has `y`, `pitch`, and `bar_y`. |

The document title is the fixed text `qbar panel`. A title from the command line is drawn on the canvas from `layout.title`. It is not copied into the document title.

## Rounding

Each Q value is converted with `float("%.6f" % value)` and then stored as a JSON number. The file is compact JSON, with no extra spaces. Non-ASCII characters are written as JSON `\u` escapes. A value read back from the file is the rounded float. It stays within 1e-6 of the aligned matrix entry.

## Escaping

`json.dumps` runs first. Then `<` is replaced by `\u003c`, `>` by `\u003e`, and `&` by `\u0026`. Those replacements are only in the JSON text. A sample id that contains `</script>` does not close the script element. The tooltip uses the string after `JSON.parse` and assigns it with `textContent`. The page source does not use `innerHTML`.

## Run field

When `--replicates` is off, every `run` string is empty. When `--replicates` is on and a K has two or more files, the string is the file name only, with no directory, of the major-mode reference replicate: the `replicates_K{k}.tsv` row whose mode id is 1 and whose `is_mode_rep` column is `yes`. When `--replicates` is on and a K has one file, the string is that file's name only, with no directory. Several files at one K are still drawn from the major-mode mean. The string names the reference file of that mode.

## Offline guarantee

The written file is searched with a regular expression. Inside each `script`, `link`, and `img` tag, and inside each `src` or `href` attribute, the text `http` must not occur and the two-character sequence `//` must not occur. The page has no `link` element, no `img` element, and no remote font. The drawing script avoids line comments so that it does not contain `//`.

When `node` is on `PATH`, the test extracts the drawing script, runs `node --check` on it, and runs a small harness that calls `sampleIndexAt` and checks a few positions, including N = 1. When `node` is absent, that part is skipped. This run had `node` 26.3.0, so both checks ran.

Browser draw time was not measured.

## Sizes

Each N starts from `numpy.random.default_rng(20261022)` and draws `dirichlet(ones(K), size=N)` for K = 2, 3, 4, 5, and 6, saved with `%.6f`. Ids run from `s00000`. The command is `qbar.py` on those five files plus the id file, with `--html`, and with no `--align-method`, so the method is greedy.

| N | File | Bytes |
| --- | --- | --- |
| 1000 | panel.html | 210176 |
| 10000 | panel.html | 2025893 |
| 50000 | panel.html | 10096425 |

At N = 50000 the file is 10096425 bytes. That is under 50 * 1024 * 1024 (52428800). No size cap was added.

## Tests

From the repository root, `python -m unittest test_qbar.py` reported `Ran 251 tests in 9.715s` and `OK`. The parent commit had 242 tests.

The new tests parse the embedded JSON and check that the iid order equals `order.tsv`, that each Q value is within 1e-6 of the aligned matrix and within 1e-12 of the 6-decimal rounding, and that `hex` equals `perm_K*.tsv`. An iid `</script><b>"&` round-trips through JSON, and the raw file does not contain `</script><b>`. The offline search above is applied to the written file. N = 1 writes `panel.html` for one K and for two K. With no groups file, every group is the default rest name `NA`. `--rest-name NONE` stores `NONE`. A default run writes no `panel.html`. With `--replicates`, the run string matches the file name of the major-mode reference, and a K with one file stores that file's name. The stored name has no directory. Without the flag the run strings are empty. `node --check` and the `sampleIndexAt` harness ran. Importing `qbar.html_panel` does not import Pillow.

The only existing test edited for this change is `test_readmes_name_every_cli_option`. `--html` is in its exemption set. It is documented in `docs/cli.md` and in this file. The READMEs do not name it.

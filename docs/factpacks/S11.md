# S11. Documentation index and tutorial

Date: 2026-10-24. This note records the documentation index, the tutorial, and a check that every long option is named in the docs. No new flag. Command-line defaults are unchanged.

## What was added

`docs/README.md` is the index. It states what qbar does, copies the install steps from the README, and links the command line, the alignment-method note, the web page, and the tutorial. It also lists each fact pack.

`docs/tutorial.md` walks through the bundled demo from install to the web page. The commands use `demo/2448/ref2448_pruned.2.Q` and `demo/2448/ref2448_pruned.3.Q`. Each copied table is from a run of that command.

`docs/factpacks/BASE.md` records five options that were already on `build_parser` and were missing from every fact pack: `--qmax`, `--anchor-group`, `--title`, `--width`, and `--bar-height`.

## Coverage test

`FactPackCoverageTests.test_every_long_option_is_in_a_fact_pack_and_in_cli_md` reads every long option from `qbar.cli.build_parser`. It skips `-h` and `--help`. A flag counts only as a whole option string, so `--q` is not treated as present inside `--q-format`. Each flag must appear in `docs/cli.md` and in at least one file under `docs/factpacks/`. A missing `docs/factpacks/` directory or a missing `docs/cli.md` fails the test.

Before `BASE.md`, the five flags above were the ones missing from every fact pack. They were already present in `docs/cli.md`.

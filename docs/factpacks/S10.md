# S10. Provenance

Date: 2026-10-22. This note records `--provenance` and `run.json`. No alignment formula changed.

## Flag

`--provenance` is `store_true`. The default is off. When the flag is absent, the run does not create `run.json`. `args.txt` is still written by the same writer as before. `README.md` and `README.zh.md` are unchanged.

## Keys

`run.json` is UTF-8, indent 2, with a trailing newline. Top-level keys are not sorted. Keys inside `resolved_options` are sorted. Every key below is present:

- `qbar_version`: string from `qbar.__version__`
- `git_commit`: stdout of `git rev-parse HEAD` when that command succeeds and the running `api.py` is a tracked file in that checkout. Otherwise the string `unknown`. A value is kept only when it is 40 hex characters.
- `argv`: JSON list of strings. The list passed into `run`, or `sys.argv[1:]` when that argument is `None`.
- `resolved_options`: every argparse dest and its value after parsing, including defaults the user did not type. Paths are strings.
- `inputs`: list of `{path, sha256, nbytes}`. Q files come first, in the order `collect_q` returned them. Then fam, ids, groups, the order file, and the color file, when those options were non-empty. `sha256` is the hex SHA256 of the file bytes. `nbytes` is the byte length.
- `numpy`, `scipy`, `pillow`, `python`: version strings. `pillow` is `PIL.__version__`. `python` is `platform.python_version()`.
- `started`, `finished`: ISO-8601 from `datetime.now().astimezone()`, so the string has a numeric UTC offset. `started` is taken at the beginning of `run`. `finished` is taken just before the file is written.
- `platform`: `platform.platform()`

## Help

This is the `--provenance` line from `qbar.py --help`:

```
  --provenance          另写 run.json，记下版本、选项、输入哈希和依赖版本 (default: False)
```

## Example

Working directory: repository root. `PYTHONHASHSEED=0`. `PYTHONDONTWRITEBYTECODE=1`. This run used Python 3.9.6.

```
python qbar.py --q demo/2448/ref2448_pruned.2.Q --fam demo/2448/ref2448_pruned.fam --outdir demo/out/s10 --provenance
```

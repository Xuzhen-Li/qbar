# F5. CV error and log-likelihood

Date: 2026-10-23. This note records optional reading of ADMIXTURE stdout. No alignment formula changed. `--id-col` stays `analysis_IID`. `--group-col` stays `Dong_Grp`.

## Flags

`--logs` is optional. It takes files, a quoted wildcard, or a directory. A directory reads `*.out` then `*.log`, each sorted, and skips a later path with the same real path. The default is off. `--logs-map` is an optional two-column file, log path and Q path, with no header. It checks pairs and does not add a column. `--logs-map` without `--logs` is an error.

## Table and plot

When `--logs` is set, the run writes `cv_loglik.tsv`, `cv_loglik.png`, and `cv_loglik.pdf`. Columns are `file`, `k`, `seed`, `cv_error`, `loglik`, `iterations`, `converged`, and `warnings`. Missing fields are the string `NA`. Numeric tokens stay as printed.

The CV line puts K in the parentheses and one number after the colon. The summary log-likelihood is the line that starts with `Loglikelihood:` and does not contain `Elapsed:`. `Initial loglikelihood:` is not that field. `converged` is `yes` when a `Converged in N iterations` line is present, otherwise `NA`.

A banner file with no CV line stays one row, with `cv_error` `NA`, and a warning that names the path. A truncated banner file warns and still returns the row. A line outside the ADMIXTURE 1.3.0 shapes is an error that names the path and that line. A file with no banner is accepted only when every non-blank line is a CV line: one row per line, and the other fields are `NA`.

The plot is 800 by 500, RGB, white. PDF uses the same Pillow save as the bar plot, resolution 150. Only rows whose `cv_error` is not `NA` are drawn. Distinct integer K values are sorted and spaced evenly. Each K has a gray min-max segment (`#888888`), a red median mark (`#b00000`, 12 px wide), a dark point for each numeric row (`#333333`, radius 4), and `n=<count>` centered on that K. The median is `numpy.median`. Axis labels are the ASCII strings `K` and `CV error`. If there is no numeric CV, both files are still 800 by 500 and contain the ASCII sentence `No CV error to plot`. Figure text stays ASCII in both languages.

## Provenance

When `--provenance` is on and `--logs` is set, each log path is appended to the existing `inputs` list, then the map path when `--logs-map` is set. When `--logs` is off, that list is unchanged.

# S3. English CLI

Date: 2026-10-23. This note records the default language of help, errors, and warnings. No alignment formula changed. `--id-col` stays `analysis_IID`. `--group-col` stays `Dong_Grp`.

## Flag

`--language` choices are `en` and `zh`. The default is `en`. `main` reads `--language` before argparse formats help, so `qbar --help` is English and `qbar --language zh --help` is Chinese. The option is a real argparse flag. Its dest is `language`, so it is included in `resolved_options` when `--provenance` is on.

Strings live in `qbar.messages.text`. Existing functions take `language` as a keyword-only argument with default `en`, so a call that does not pass it still gets English.

English text uses only code points below 128. The Pearson warning uses the word `to` where the Chinese text uses U+2192. The Chinese hclust help keeps U+2212 in `1−Pearson`. The English help uses `1-Pearson`.

The module docstring of `cli.py` is English and is still `qbar.__doc__`. The Chinese one-line description is only in the `zh` parser text:

```
读 ADMIXTURE 的 Q，按指定规则排人，跨 K 对齐列，写出结构条形图。
```

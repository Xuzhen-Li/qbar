# S6. Map pies

Date: 2026-10-24. This note records an optional site pie map. `--sites` is omitted by default. A default run writes neither `map_pies.png` nor `map_pies.tsv`. `--id-col` stays `analysis_IID`. `--group-col` stays `Dong_Grp`. `--palette` stays `science`.

## What

`qbar.mappies.pies(sites, q, groups, colours, legend=None, *, k=None, basemap_image=None, bbox=None, language="en")` returns `(image, geometry)`. `sites` is a TSV path or a list of records. Pillow is imported only inside `_draw`. Importing `qbar.mappies` does not import Pillow. Planning the geometry does not import it.

Nothing is downloaded. Cartopy is not used. A coastline is not drawn. A world file is not read. `--vector` does not write `map_pies.pdf` or `map_pies.svg` in this step, including when the bar figures are vectors.

The three flags are documented here and in `docs/cli.md`. The README option list does not name them yet.

## Sites file

The file is UTF-8. A leading BOM is ignored (`utf-8-sig`). Fields are split on tabs. Blank lines are ignored. The header must be `site`, `latitude`, `longitude`, `group`.

A site's samples are the rows whose group equals that value. The group column is `--group-col` (default `Dong_Grp`), or the labels from `--groups`. An empty group cell has already been replaced by `--rest-name` before the pies see it.

## Mean Q and colours

K is `--sort-k` when that flag is set, otherwise the largest K among the inputs. Q is the aligned matrix at that K. Column order and colours match the bar for that K, including `--palette`, `--color`, `--color-file`, and colours and names from `--state`.

Mean Q is the arithmetic mean of every sample in the site group. The bar draws every row of the aligned matrix. `--align-mode core`, `--align-groups`, and the row masks used by bootstrap and permutation change which rows match columns. They do not remove rows from the bar, and they do not remove rows from this mean. A row kept after the row-sum warning is included.

## Canvas

The canvas is white and 1600 px wide. Margins are fixed: left 84, right 340, top 42, bottom 58. The plot width is 1176 px. The plot height is `max(1, round(1176 * lat_span / lon_span))`. There is no height cap. A latitude span much larger than the longitude span makes a tall image, and the 2x buffer is allocated first.

x is longitude and y is latitude, with y increasing downward so latitude increases upward. The degrees-per-pixel scale is the same on both axes except for the integer height. This is not a projection. The figure draws the text `longitude, latitude, as given, no projection`, plus `longitude` and `latitude` titles and tick labels.

The data box starts from the sites that are drawn. A skipped site does not move it. An axis whose raw span is below 1 degree is widened to 1 degree about its center. Each side then grows by 10 percent of that span. `--basemap-bbox` replaces this box and is not padded.

Radius is `40 * sqrt(n / n_max)` pixels, and at least 6. `n_max` is the largest sample count among the pies that are drawn.

Wedges start at 12 o'clock and go clockwise in aligned column order. Pillow measures angles from 3 o'clock, clockwise, so the first wedge starts at -90 degrees. The sweep is `360 * mean_q / sum(mean_q)` when the sum is positive, so a mean that is slightly off 1 still fills the circle. The mean stored on the pie and in the TSV is the unscaled average. A sum of 0 stores zero sweeps and draws no wedges. A sweep of 0.000001 degrees or less is kept in the geometry and is not painted. A sweep of at least 359.999 degrees is painted as an ellipse, because a full-turn pieslice can fail to fill.

Sites that share a latitude and a longitude, compared as the parsed floats, keep the first pie in place. Each later pie in file order is shifted a further 4 px right (4, 8, 12 px ...). The warning names those sites. The shift is in final pixels.

The legend uses the same names as the bar legend for that K. Site labels sit to the right of each pie.

The picture is drawn at 2x and resized with Pillow `Image.Resampling.LANCZOS`. The filter is fixed. There is no clock and no random source in the draw. Two runs in one environment write the same PNG bytes. The label font is the first face `plot_static.load_font` finds. A different face can change the PNG bytes. The geometry and the TSV do not use the font.

## Basemap

`--basemap-image` and `--basemap-bbox` must be passed together, and both require `--sites`. The box is `LON_MIN,LAT_MIN,LON_MAX,LAT_MAX`. Both spans must be positive, and the four numbers must be finite. A leading minus is accepted: a value such as `-10,-10,10,10` does not match argparse's negative-number pattern, because of the commas, so the parser joins it to the flag before parsing.

The image is stretched to the plot rectangle for that box. An alpha channel is composited onto white first. A pie whose longitude or latitude is outside the closed box is warned, named, and still drawn. Drawing is clipped to the plot rectangle. A world file is not read.

## Outputs

`map_pies.png` and `map_pies.tsv` are written in the output directory only when `--sites` is set and the run finishes. The table header is `site`, `latitude`, `longitude`, `group`, `n`, `K`, then `C1` through `CK` in aligned column order. Latitude, longitude, and each mean use `%.6f`. The file is UTF-8 and ends with a newline. A renamed legend stays on the figure. It does not rename `C1` through `CK`.

`sites` and `basemap_image` are file-valued options in `config_resolved.json`, stored as base names. `basemap_bbox` is the four numbers, not a path.

A basemap pair error is raised before the Q files are read. A bad sites file, a missing image, and an unreadable image are raised before the output directory is created.

## Errors

| Case | What the message names |
| --- | --- |
| The sites file is missing or cannot be opened | the path as given |
| The sites file is not UTF-8 | the path as given |
| The header is not the four names | the header that was read |
| A line is not four tab-separated fields | the line number |
| There are no data rows | that the file has no data rows |
| A site name or a group is empty | that site |
| A site name is repeated | that name |
| Two rows name the same group | the group and those site names |
| Latitude is missing, not finite, or outside [-90, 90] | the site and the value |
| Longitude is missing, not finite, or outside [-180, 180] | the site and the value |
| Every site is skipped | that every site was skipped |
| The group list length does not match the Q rows | both counts |
| The colour list length does not match K | K and the count |
| One of `--basemap-image` and `--basemap-bbox` is missing | that the two flags must be together |
| Those flags are set without `--sites` | that `--sites` is required |
| The image file is missing | the path as given |
| The image cannot be read | the path as given |
| The box is not four finite numbers with a positive span | the value |

| Warning | What it names |
| --- | --- |
| A site group has no samples | the site and the group; that pie is skipped |
| Two or more sites share coordinates | those site names; each later pie is shifted a further 4 px right (4, 8, 12 px ...) |
| A pie is outside the basemap box | that site; it is still drawn, clipped |

Wedge spans equal `360 * mean_q` when the row sums to 1, and `360 * mean_q / sum(mean_q)` when a row is 0.50 and 0.52. The stored mean stays unscaled. A 50/50 wedge that starts at -90 puts the first colour at 3 o'clock. Radius for n = 1 against n = 4 is 20 and 40. Radius for n = 1 against n = 100 is clamped from 4 to 6, and the large pie stays 40. Shared coordinates shift each later pie a further 4 px (4, 8, 12 px ...) and the warning names those sites. An empty group warns and is left out of the TSV.

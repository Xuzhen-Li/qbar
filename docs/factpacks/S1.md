# S1. Replicates and modes

Date: 2026-10-23. This note records optional grouping of same-K Q files. `--id-col` stays `analysis_IID`. `--group-col` stays `Dong_Grp`. The procedure is qbar's own.

## Flags

`--replicates` is optional and off by default. It accepts several Q files at one K, groups them into modes, and aligns the major-mode mean across K. Without the flag, two files at one K still exit with the existing duplicate-K error. The English text is `K=%(k)s has two Q files: %(path_a)s and %(path_b)s`.

`--mode-sim-cut` is a float with no default. It is required when `--replicates` is on. No default cut is shipped, because none has been calibrated. The English error is `--replicates requires --mode-sim-cut. No default cut is shipped because none has been calibrated.` Passing `--mode-sim-cut` without `--replicates` exits with `--mode-sim-cut requires --replicates`. The cut must be in `[0, 1]`. Any other value exits with a message that names the value.

When `--replicates` is on and every K has exactly one file, the cut is still required, no `replicates_*.tsv` file is written, and the loaded matrices are passed on unchanged. The existing outputs then match the same command without `--replicates`.

## Pair similarity and modes

`modes_for_k` in `src/qbar/modes.py` takes a list of `(path, matrix)` for one K. Paths are sorted, and a tie keeps the first path in that order. The module does not import PIL. `seed` is accepted and returned. The steps do not draw random numbers.

Column similarity follows the active `--align-method`. Greedy and hungarian use Pearson, through `col_pearson` and `pearson_matrix` with an all-true mask. Pong uses `pong_sim` on each column pair. Jaccard uses `jaccard_matrix` with the given set and cut. That builds a K by K matrix `S`.

The pair alignment is a one-to-one assignment that maximises the sum of `S`, using `scipy.optimize.linear_sum_assignment(maximize=True)`. This assignment is used for every method, including greedy. Pair similarity is the mean of the matched `S` values. The permutation places the second replicate's columns into the first replicate's column order.

The K reference is the replicate with the highest median pair similarity to the others. The median is the middle value, or the average of the two middle values when the count is even. Ties keep the first sorted path. One replicate has no pairs: that file is the reference.

A mode is a connected component of the undirected graph that links two replicates when their pair similarity is greater than or equal to the cut. A negative similarity is not linked at cut 0. Mode ids start at 1. Modes are ordered by size, largest first, then by higher mean within-mode pair similarity, then by the smallest sorted path in the mode. A singleton has no within-mode pair, so that mean is missing and ranks after any number when the size is the same. The major mode is mode id 1.

The mode reference is the member with the highest median pair similarity to the other members. Ties keep the first sorted path. A singleton is its own reference.

The mode mean permutes every member into the mode reference's column order, averages the matrices elementwise, and renormalises each row so that it sums to 1. If a mean row sums to 0, the run exits with `Mode %(mode)s at K=%(k)s has a row whose mean sums to 0` and does not divide by zero.

Across K, the major-mode mean is the matrix passed to the existing alignment when that K has two or more files. A K with one file keeps the loaded matrix. Minor modes are written. They are not dropped.

## Files

For each K with two or more files, `replicates_K{k}.tsv` has columns `K`, `replicate_file`, `mode_id`, `is_mode_rep`, `sim_to_k_ref`, `sim_to_mode_ref`, and `perm`. `is_mode_rep` is `yes` or `no`. `perm` is the 1-based column indices of that replicate in mode-reference order, joined by commas. Similarities use `%.6f`. A similarity of a row to itself is `NA`, not `1.000000`. Paths are the strings collected from the Q list.

`replicates_summary.tsv` has one row per such K and columns `K`, `n_replicates`, `n_modes`, `major_mode_id`, `major_mode_size`, and `major_mode_mean_sim`. The last of those is `NA` when the major mode is a singleton. `mode_mean_K{k}_mode{m}.Q` is written for every mode at that K, including minor modes, with `%.6f` and spaces between columns.

`args.txt` writes one `K{k}` line per input file. When several files share a K, those lines are in sorted path order. One file stays one line.

When `--provenance` is on, every replicate file is already in `inputs`, because that list is the Q list from `collect_q`.

## What this is not

This is not CLUMPAK's MCL (Kopelman et al. 2015, Molecular Ecology Resources 15(5):1179-1191, p. 1181, DOI 10.1111/1755-0998.12387). It is not pong's cliques at 0.97 (Behr et al. 2016, Bioinformatics 32(18):2817-2823, section 2.2, DOI 10.1093/bioinformatics/btw327). It is not Clumppling's Louvain (Liu, Kopelman, and Rosenberg, DOI 10.1093/bioinformatics/btad751, paper section 3.4, p = 0.01, text extracted 2026-10-22).

## Tests

From the repository root, `python -m unittest test_qbar.py` reported `Ran 124 tests in 3.485s` and `OK`.

The new tests say the numbers are invented. Three N = 6, K = 2 matrices are a block, that block with the columns swapped, and a different block pattern. The test computes Pearson on the columns and then both permutations of K = 2. A cut between those pair similarities gives mode sizes 2 and 1. The major mode is the block and its swap, and the major mean equals the block after renormalisation. Two identical matrices have pair similarity 1 for greedy, and the same for hungarian, pong, and jaccard on that fixture. Cut 0 links three column permutations of one matrix into one mode. A cut above every pair similarity gives singletons, and mode 1 is the smallest path. Two modes of size 2 are ordered by mean similarity even when the lower similarity has the smaller path. A mean row that sums to 0 raises the English message, and `zh` raises the Chinese one. Without `--replicates`, two files at one K raise the original duplicate-K message. `--replicates` without `--mode-sim-cut` raises the English sentence above, and `--language zh` raises the Chinese sentence. `--mode-sim-cut` without `--replicates` is an error. A cut outside `[0, 1]` names the value. One file at every K, with `--replicates` and a cut, matches the run without those flags by SHA-256 on `order.tsv`, `perm_K*.tsv`, the PNG files, the PDF files, and `align.tsv`, and it writes no replicates file. The major-mode mean is what the across-K alignment sees: a replicate run whose major mean equals one block file matches a run of that file on those same outputs, and the minor-mode Q file is still written. `--provenance` lists every replicate path. `--id-col` stays `analysis_IID` and `--group-col` stays `Dong_Grp`.

## Public API

```python
def run(args: argparse.Namespace, argv: list[str] | None = None) -> RunResult
```

`args` is the `argparse.Namespace` from `build_parser`. Attribute names are that parser's option dests. A mapping is not accepted.

`RunResult` fields: `aligned`, `permutations`, `order`, `spans`, `colours`, `paths`.

K is the column count. Permutations are 0-based in `permutations` and 1-based in the `perm_K` TSV files. `colours` is the hex map written into the figure. `paths` lists files in write order.

`argv` is what `args.txt` records. `None` uses `sys.argv`. A list is written as the word `qbar` followed by that list.

`cli.main(argv=None)` parses with `build_parser`, calls `run(args, argv)`, and returns 0.

## Import rules

`cli` may import `api` and the lower modules. `api` does not import `cli`. Only `plot_static` imports Pillow. Importing `io`, `align`, `order`, `report`, or `api` does not import Pillow. Imports inside the package are relative. There is no import cycle.

## Import modes

Checkout: the repository root `qbar.py` is what `import qbar` finds when that directory is on `sys.path`. It sets `__path__` to `src/qbar`, then executes `src/qbar/__init__.py` in its own namespace. `__file__` stays the repository root `qbar.py`.

Installed: `import qbar` loads the package. `__file__` ends with `qbar/__init__.py`. The console script is `qbar.cli:main`. `python -m qbar` runs `src/qbar/__main__.py`, which calls `cli.main`.

Names that `import qbar` exposed before this change are still exposed. New public names from the checkout launcher: `RunResult`, `align`, `api`, `cli`, `io`, `order`, `report`, `run`. New public names from the installed package: `RunResult`, `align`, `api`, `io`, `order`, `report`, `run`. The installed package already exposed `cli`.

## Example

Run from the repository root, so `import qbar` is the checkout launcher. Interpreter: Python 3.9.6. numpy 2.0.2, scipy 1.13.1, Pillow 11.3.0.

```python
import qbar
argv = ["--q", "demo/2448/ref2448_pruned.2.Q", "demo/2448/ref2448_pruned.3.Q", "--fam", "demo/2448/ref2448_pruned.fam", "--groups", "demo/2448/groups.tsv", "--id-col", "id", "--group-col", "group", "--within", "iid", "--align-method", "hungarian", "--outdir", "out/api_example"]
result = qbar.api.run(qbar.build_parser().parse_args(argv), argv)
print(result.permutations[2])
print(result.permutations[3])
print(len(result.order), len(result.paths))
```

Output:

```
out/api_example/panel.png
order	out/api_example/order.tsv
[0, 1]
[2, 0, 1]
2448 12
```

`run` prints the panel path and the `order.tsv` line before it returns. The last three lines are the K=2 permutation, the K=3 permutation, the sample count, and the number of paths.

qbar

loading

Three steps. The program runs in this browser.

Your files stay in this browser. They are not uploaded. The page loads one pinned Pyodide build and the local qbar wheel while the status says loading. After the status says ready, the page does not make another network request. The run and the downloads stay in this browser.

1. Load files

You can also drop Q files on this box.

Sample file

Blank column names use those defaults. They are the command-line defaults.

The limit is 200 MB, which is 209715200 bytes, for all selected files together. A larger total is refused and names that size.

    2. Choose

    K is taken from the file names after you choose Q files. K from and K to must both be integers. A blank value, or a value that is not an integer, is an error and the run does not start.

    The default is greedy. After the status says ready, the list is the methods in this qbar package.

    3. Run and view

    off is the default. pdf, svg, and both match --vector. PNG is written when a run finishes. PDF and SVG need a font file this browser run does not have, so those choices show the program's own message. PNG uses the built-in font.

    Downloads

    Each file is downloaded on its own. A zip is not offered.
